# CRA Label SBOM: demo

Sample dependency files for testing [CRA Label SBOM](https://github.com/Shauliko/cralabel-sbom-action) on Linux and Windows runners:

- `npm/`: a `package-lock.json` generated by npm (Express, ws, ESLint as a dev dependency)
- `python/`: a pinned `requirements.txt`
- `go/`: `go.mod` and `go.sum` from spf13/cobra v1.8.0
- `tools/`: a `package.json` with no lockfile, to show how unpinned versions are reported

The repository deliberately has no `SECURITY.md`, so the job summary shows the vulnerability-contact notice. Open the latest run under Actions to see the summary and download the artifacts.
